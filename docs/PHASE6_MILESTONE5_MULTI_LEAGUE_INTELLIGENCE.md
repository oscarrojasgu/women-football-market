# Phase 6 — Milestone 5: Multi-League Intelligence

Status: Complete

## Objective

Build evidence-based cross-league intelligence for women’s football without inventing an arbitrary league-strength score or turning descriptive statistics into player ratings.

## Database intelligence

### Global peer benchmarks

The `player_global_peer_benchmarks` view compares eligible player-season records across WFM competitions using:

- Same season
- Same normalized position
- Minimum 450 recorded minutes
- Minimum peer-group size of 5

It exposes global percentiles for:

- Goals / 90
- Assists / 90
- xG / 90
- xA / 90
- Chances Created / 90
- Key Passes / 90
- Tackles / 90
- Interceptions / 90
- Progressive Carries / 90
- Duels Won / 90

Validation at milestone completion:

- 163 global benchmark rows
- 153 players with global benchmark context

### Competition distribution context

The `competition_stat_context` view describes the statistical environment for:

- Season
- Competition
- Position

It provides recorded player count, total minutes, and competition-position averages for the same per-90 metrics.

Validation at milestone completion:

- 41 competition-context rows
- 6 competitions represented

### Normalized competition/season architecture

Global intelligence uses the normalized competition-season relationships established in Milestone 1 rather than treating legacy player league text as canonical.

## Methodology

WFM does not currently assign a single league-strength score. Cross-league evidence is presented in layers:

1. Individual player production
2. Competition-relative peer context
3. Global same-position/same-season percentile context
4. Competition-position distribution context
5. Cross-league player context combining the available evidence

This avoids implying that a percentile or average is a direct adjustment for league quality.

## Coverage and limitations

Global intelligence is limited by the data currently recorded in WFM. Missing competition context is shown as unavailable rather than estimated.

The benchmark population requires sufficient minutes and peer-group size, so not every player or competition will receive global context.

No unsupported exchange rates, player ratings, league-strength scores, or future-performance projections are generated by this milestone.
