# Phase 6 — Global Expansion

Status: COMPLETE

## Milestones

- M1 — League Expansion: completed through multi-competition player, club, contract, transfer, market-value and statistics structures.
- M2 — International Coverage: completed at the application layer through global player discovery, nationality, competition and cross-market criteria.
- M3 — Contracts & Salaries: completed with USD salary context, contract status, expiration filtering, source traceability and club salary coverage.
- M4 — Transfers & Market Values: completed with transfer and market-value context integrated into club and scouting workflows.
- M5 — Multi-League Intelligence: completed with same-season global peer benchmarks, season-aligned intelligence, percentile context and competition coverage.
- M6 — Global Scouting Network: completed with reusable scouting profiles, club-linked recruitment context, discovery, persistent lists, pipeline workflow, notes, action center, candidate comparison, player reports, evidence and source traceability.

## Completed Global Scouting Workflow

1. Club profile → Scout this club.
2. Club context → active squad, expiring contracts, salary coverage, transfer activity and position mix.
3. Scouting profile → reusable recruitment criteria.
4. Global discovery → candidates across WFM data.
5. Candidate selection → persistent scouting lists.
6. Player report → performance history, recruitment context, evidence and source traceability.
7. Comparison → side-by-side factual candidate context.
8. Pipeline → stage, priority, target date and next action.
9. Notes → private recruitment research.
10. Action center → active recruitment follow-up.
11. Global peer context → same-season descriptive percentile data.

## Guardrails

- Missing data remains missing rather than being converted into fabricated zeroes.
- Peer comparisons are season-aligned.
- Evidence and source records are displayed where available.
- Workflow fields do not create player ratings.
- Candidate comparison does not select an overall winner.
- Club context is descriptive and does not automatically determine recruitment need.

## Phase 6 Exit Criteria

The WFM application now has the software foundation for a global scouting network connecting clubs, profiles, international player discovery, evidence, comparison and recruitment workflow.

Next phase: launch readiness — data expansion and verification, QA, security/permissions, performance, legal/attribution, SEO/branding and production launch.
